## Tech

- Plain HTML / CSS / JS — no framework, no build step
- Mobile-first responsive design
- Sticky tap-to-call header and bottom CTA bar
- Menu tab system (Gelato, Drinks, Desserts, Food)
- Three-location grid with hours and directions
- Services section (weddings, catering, wholesale)
- JSON-LD structured data (`IceCreamShop`, `LocalBusiness`)
- Proper `<meta>`, Open Graph, and canonical tags
- Unsplash stock images with `auto=format` WebP, hero eager-loaded, rest lazy-loaded
- `robots.txt` set to `Disallow: /` to prevent indexing
